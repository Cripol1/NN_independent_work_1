# Классификация родов грибов с помощью ResNet50 (Transfer Learning & Fine-Tuning)

Самостоятельная работа по курсу нейронных сетей: решение задачи многоклассовой классификации изображений грибов (9 родов) на фреймворке **PyTorch**.

## 1. Описание данных и подготовка (EDA)
**Исходный датасет:** 6 714 изображений (медианный размер `800×580`), распределенных по 9 классам: *Agaricus, Amanita, Boletus, Cortinarius, Entoloma, Hygrocybe, Lactarius, Russula, Suillus*.
**Очистка данных:** Выявлены и удалены 2 поврежденных (обрезанных) JPEG-файла; 2 черно-белых изображения автоматически приведены к формату `RGB` при загрузке.
**Разбиение:** Выполнено разделение выборки в пропорции **80% train** (5 371 изображение) / **20% test** (1 343 изображения) с загрузкой через `torchvision.datasets.ImageFolder`.
**Дисбаланс:** Между самым крупным классом (*Lactarius*, 1563 фото) и редкими классами (*Hygrocybe*, *Suillus*, ~ 311 фото) наблюдается 5-кратный перекос. Для компенсации использованы обратно пропорциональные веса классов в `nn.CrossEntropyLoss(weight=...)`.

## 2. Подход и обучение модели
В качестве базовой архитектуры выбрана предобученная на ImageNet сеть **ResNet50** (`ResNet50_Weights.DEFAULT`):
**Предобработка и аугментация:** Для тестовой выборки использована строгая эталонная нормализация ImageNet. Для обучающей выборки добавлены аугментации (`RandomResizedCrop`, горизонтальные и вертикальные отражения, повороты до 25°, `ColorJitter`) с сохранением статистики нормализации ImageNet.
**Этап 1 — Feature Extraction (10 эпох):** Заморозка всей сверточной основы (`backbone`), замена выходного слоя на `Dropout(0.3) + Linear(2048, 9)` и обучение только классификатора (`Adam`, `lr=1e-3`).
**Этап 2 — Fine-Tuning (5 эпох):** Разморозка глубокого сверточного блока `layer4` для адаптации признаков под текстуры грибов. Использован оптимизатор `AdamW` с дифференцированным шагом обучения (`lr=5e-5` для `layer4` и `2e-4` для `fc`) и планировщиком `CosineAnnealingLR`.

## 3. Результаты

| Этап обучения | Обучаемые слои | Эпохи | Лучшая точность на тесте (Accuracy) |
| :--- | :--- | :---: | :---: |
| **Этап 1 (Feature Extraction)** | Только классификатор (`fc`) | 10 | **79.02%** |
| **Этап 2 (Fine-Tuning)** | Блок `layer4` + `fc` | 5 | **91.41%** |

### Основные выводы
**Эффективность дообучения:** Разморозка последнего сверточного блока `layer4` с малым шагом обучения дала прирост точности на **+12.39%** на тестовой выборке без переобучения.
**Анализ матрицы ошибок:** Взвешивание классов позволило добиться высокой точности даже на малочисленных родах (*Agaricus*, *Hygrocybe*, *Suillus*). Основные ошибки сосредоточены между родами *Russula* и *Lactarius*.
